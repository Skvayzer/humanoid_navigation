# ikd-Tree
ikd-Tree is an incremental k-d tree for robotic applications.

Vendored from https://github.com/hku-mars/ikd-Tree, branch `fast_lio`, commit e2e3f4e (2022-02-08),
which FAST_LIO used as a submodule. Local change: `Multi_Thread_Rebuild_Point_Num` can be overridden
at compile time (see `IKD_SYNC_REBUILD` in the package CMakeLists.txt).
